# Phase 04 supporting materials (DRAFTS)

**Status: DRAFT, NOT APPROVED.** These are the practical documents the Phase 04 protocol (`docs/ROADMAP_PHASE04_RESEARCH_PROTOCOL.md`, §11–12) says must exist before a study can start. They contain no participant data and no results. They can be written now because they do not depend on the open decisions, but **nothing here may be used with a real participant** until the professor has confirmed the decisions marked PENDING PROFESSOR APPROVAL and the ethics route (Q-07) has been settled. Where a document needs institution-specific wording, it says `[TO BE FILLED]`.

| File | What it is | Depends on (still open) |
|---|---|---|
| `01_participant_information_sheet_DRAFT.md` | what a volunteer is told before agreeing | ethics wording (Q-07); population (D-05) |
| `02_consent_form_DRAFT.md` | written consent form (the dossier §4 requires written consent) | ethics wording (Q-07) |
| `03_background_questionnaire_DRAFT.md` | short background questions, no name or ID numbers | none for the questions; ethics review of the text |
| `04_session_script_and_checklist_DRAFT.md` | what the experimenter says and does, safety and stop rules, equipment checklist, pilot checklist | trial counts (Q-03), seated vs standing (Q-04) |
| `05_counterbalancing_sheet.md` | which condition order each enrolment slot gets (AB/BA) | design (D-04) |
| `06_analysis_plan_DRAFT.md` | the analysis written down before any data exists | outcomes (Q-01), formula (D-02), sample size (Q-07) |

Rules that apply to every file here:
- Participants are identified only by pseudonymous IDs (P01, P02, ...). No name, roll number or email goes into any data file or questionnaire sheet.
- The project team's own test sessions are labelled `Selftest`, get no P-number, and are never counted or reported as participants.
- No audio and no video are recorded.
- Decision labels follow the protocol: **CONFIRMED** (none yet), **PROPOSED**, **PENDING PROFESSOR APPROVAL**, **UNRESOLVED**.
